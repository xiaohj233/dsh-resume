# Third-Party Notices

This repository contains compatibility patch definitions and compressed test fixtures derived from files in DeepSeek Harness packages. The package archive published by `npm pack` excludes the test fixtures, but the source repository retains them for exact patch/restore regression tests.

## DeepSeek Harness

Affected packages include `@deepseek-ai/dsh-agent-loop`, `@deepseek-ai/dsh-session`, and `@deepseek-ai/dsh-client-ui-conversation` at version `0.1.0-rc.6`.

Source: https://github.com/deepseek-ai/deepseek-harness
